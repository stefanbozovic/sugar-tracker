# Sugar Tracker

Lični timeline glukoze, obroka i insulina.

## GitHub Pages

U GitHub repou otvori **Settings → Pages**, zatim pod **Build and deployment** izaberi:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Nakon čuvanja, sajt će biti dostupan na:

`https://stefanbozovic.github.io/sugar-tracker/`

## Ažuriranje

Timeline se održava direktno kroz ChatGPT razgovor. Kada se pošalje novo merenje, obrok ili insulin, `index.html` se dopunjava novim događajem.

> Ovo je lični dnevnik podataka, ne medicinski uređaj niti zamena za individualni plan terapije.
